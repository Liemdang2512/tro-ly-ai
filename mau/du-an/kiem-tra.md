# Kiểm tra trước khi giao — {{TEN_DU_AN}}

> Danh sách cần đạt trước khi coi là xong. Trạng thái: **chưa làm** · **đạt** · **lỗi** · **bỏ qua** (bắt buộc ghi lý do).
> Không đánh "đạt" khi chưa thật sự kiểm tra.

| Hạng mục | Trạng thái | Ghi chú | Cập nhật |
|---|---|---|---|
| Số liệu có nguồn, đã cộng/tính lại | chưa làm | | |
| Tên người, tên đơn vị, ngày tháng đúng | chưa làm | | |
| Người dùng đã xem và đồng ý bản cuối | chưa làm | | |
